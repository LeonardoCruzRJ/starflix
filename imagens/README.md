# Imagens do README

Capturas de tela da seção **Capturas de tela** do `README.md`. Para trocar uma, substitua o arquivo mantendo o **mesmo nome** (o README não precisa mudar). Formato: `.png`.

| Arquivo | Posição na galeria |
|-|-|
| `1.png` | linha 1, esquerda |
| `2.png` | linha 1, direita |
| `3.png` | linha 2, esquerda |
| `4.png` | linha 2, direita |
| `5.png` | linha 3, esquerda |
| `6.png` | linha 3, direita |

Para mais imagens, siga a numeração (`7.png`, `8.png`...) e acrescente uma linha `<img src="imagens/7.png" ...>` na galeria do `README.md`.

Esta pasta **não é baixada na instalação** (`install.sh` usa sparse-checkout e `.gitattributes` marca `export-ignore`).
