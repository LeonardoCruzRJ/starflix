# StarFlix

Servidor de vídeo próprio, local, em Linux, com visual estilo Plex.
Stack: Python/Flask + SQLite + FFmpeg + web (JS puro + hls.js) + app Android (por último).

## Instalação (Linux)

```bash
sudo apt install -y python3-pip ffmpeg    # ffmpeg >= 5 recomendado (limita o ritmo de escrita do HLS); no 4.x funciona sem esse limite
cd <pasta-do-projeto>                     # onde estiver (ex.: /data/starflix); todos os caminhos partem daqui
sudo python3 -m pip install --break-system-packages -r requirements.txt
```

As chaves de API (TMDB, TVDB, SubDL — legendas — e OMDB — esta ativa as notas IMDb/Rotten Tomatoes; sem ela só aparece a nota TMDB) e o idioma de cada um ficam em **Configurações → Agentes** (45.5/45.7), no banco, e valem assim que são salvas; outras variáveis (opcional) em `scripts/.env` (já vem no projeto; `STARFLIX\_DATA` e `STARFLIX\_SECRET` ficam comentadas, não deixe vazias).

Serviço:

```bash
sed "s|@DIR@|$PWD|g" scripts/starflix.service | sudo tee /etc/systemd/system/starflix.service >/dev/null
sudo systemctl daemon-reload
sudo systemctl enable --now starflix
```

Teste de regressão (usa dados temporários): `python3 scripts/smoke\_test.py` (a partir da pasta do projeto).

Acesse `http://IP-DO-SERVIDOR:32000` e crie o primeiro admin.

**Descoberta na rede local (mDNS):** o servidor se anuncia como `\_starflix.\_tcp` para os apps o acharem sozinhos (liga/desliga em **Admin → Servidor**). Em Docker use `network\_mode: host`, senão o multicast não sai do contêiner; redes com isolamento de clientes (Wi-Fi de visitantes) ou VLANs diferentes bloqueiam o mDNS, e aí os apps usam o endereço externo definido em **Admin → Servidor**.

**Endereço externo e conexão dos apps:** o APK não traz endereço fixo. Em **Admin → Servidor** informe o nome e o endereço externo (domínio ou IP, `https://` ou `http://`, `:porta` opcional); sem ele o site usa o endereço pelo qual foi aberto. No celular: na mesma rede o app acha o servidor sozinho (mDNS); fora dela, em **Configurações → Conectar Celular** (menu do avatar ou barra lateral) gere o **QR code** (60 s) ou o **link** (24 h), ambos de uso único, e leia o QR no app ou abra o link; os celulares conectados aparecem na mesma página, com **Revogar**. Na TV: o app procura o servidor na rede; se não achar, mostra um QR para o celular já conectado ler (Configurações → Conectar uma TV → **Ler QR code da TV**); em último caso, **Digitar endereço**.
